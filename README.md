# XpressVault 🔐

A secure, modern cloud-based document storage app built with Node.js, Express, MongoDB, and Supabase — featuring a clean UI powered by Tailwind CSS and Flowbite. Designed for seamless file uploads, JWT-secured routes, and user-centric dashboard experience.

## 🌟 Features

- ✅ User authentication with JWT + bcrypt
- 🔐 Protected routes via custom middleware
- ☁️ Upload documents to Supabase Storage
- 🗃️ Track file metadata in MongoDB
- 🎨 Modern frontend using Tailwind CSS + Flowbite
- 📄 EJS templating for dynamic views

## 🛠️ Tech Stack

### 🧠 Backend

| Tech               | Role                          |
|--------------------|-------------------------------|
| Node.js            | Runtime                       |
| Express.js         | Server framework              |
| MongoDB + Mongoose | Database + ODM                |
| Supabase Storage   | File storage solution         |
| JWT (jsonwebtoken) | Auth tokens                   |
| bcrypt             | Password hashing              |

### 🎨 Frontend

| Tech          | Purpose                          |
|---------------|----------------------------------|
| Tailwind CSS  | Utility-first styling            |
| Flowbite      | Pre-built interactive components |
| EJS           | Templating engine                |
