# XpressVault 🔐

A secure, cloud-based document storage and management platform built with Node.js, Express, MongoDB, and Supabase. Designed for individuals and teams to upload, organize, and access important documents with ease and security.

## 🌟 Features

- ✅ User authentication with JWT and bcrypt
- ☁️ File uploads directly to Supabase Storage
- 🗃️ Files linked to authenticated users in MongoDB
- 🧾 File metadata management (name, upload date, owner)
- 🔐 Secure endpoints protected by middleware
- 🎨 EJS-based templating for frontend pages

## 🛠️ Tech Stack

| Technology         | Description                     |
|--------------------|---------------------------------|
| Node.js            | Runtime environment             |
| Express.js         | Web framework                   |
| MongoDB + Mongoose | Database & ODM                  |
| Supabase Storage   | Cloud file storage              |
| Multer             | File handling middleware        |
| JWT (jsonwebtoken) | Authentication tokens           |
| bcrypt             | Password hashing                |
| EJS                | Templating engine               |
